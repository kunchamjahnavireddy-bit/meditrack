Replaces manual paper-based hospital records with a modern, secure, digital management workflow. Designed for patients, doctors, and system administrators.

⚡ Features About the Project

Core capabilities implemented in MediTrack

📝

1. Patient Registration & Auto PAT ID

Automatically assigns unique Patient IDs (PAT001, PAT002, PAT003...). Captures demographics and validates phone numbers, emails, and ages to prevent duplicate records.

🩺

2. Medical Profile Management

Maintains a comprehensive medical file connected to the Patient ID. Stores Blood Group, Known Allergies, Existing Chronic Diseases, Medical History, Medications, Emergency Contact, and Insurance details.

🗓️

3. Smart Appointment Scheduling

Real-time slot picker (09:00 AM – 04:00 PM). Features strict Double-Booking Collision Prevention at both frontend and database levels so a booked slot immediately becomes unavailable.

🔍

4. Unified Patient Directory Search

Doctors and administrators can search by Patient ID, Name, or Phone Number to inspect the unified patient file (Demographics + Medical Record + Appointment History).

🩺

5. Doctor Clinical Workspace

Dedicated physician workspace displaying daily consultation agendas, clinical consultation notes, and patient record inspection drawers.

⚙️

6. Admin Security & Control Center

Administrative control center for live MongoDB analytics, doctor credential authorization, user account management, permanent deletion, and audit logging.
